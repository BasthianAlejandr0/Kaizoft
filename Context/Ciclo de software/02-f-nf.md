## Requerimientos:
### Requerimientos funcionales:
1. RF-01: EL sistema debe permitir enviar formularios con su respectiva consulta del cliente
2. RF-02: El sistema debe mostrar quienes somos
3. RF-03: El sistema debe tener un apartado para poder contactarnos
4. RF-04: EL sistema debe tener mostrar los servicios que ofrecemos


### Requerimientos no funcionales:
1. RNF-01: EL sistema debe permitir guardar los formularios en una base de datos para persisitencia y tambien poder enviarlo al correo electrónico
2. RNF-02: El sistema debe ser responsivo
3. RNF-03: El contacto debe redireccionar de manera automática al sitio de destino (wsp, ig, lIkdn)
